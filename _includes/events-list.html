{%- comment -%} Renders a list of event cards bucketed by date, driven by site.data.events. Included twice on the Activities page (homepage), once per section. Parameters: events - required, a list of event hashes (title, institution, start, end [optional], url [optional], organized_by [optional]) mode - required, "upcoming" or "past". "upcoming" shows events whose end (or start, if no end) is >= today, sorted soonest-first. "past" shows the rest, sorted most-recent-first. organized_by: true switches the institution line from "At {{ institution }}" to "Organized by {{ institution }}" -- use it for workshops run by a lab/institution at a different physical venue (e.g. Xitou, Tour de Formosa), not for events simply hosted at a university. {%- endcomment -%} {%- assign today = site.time | date: "%Y-%m-%d" -%} {%- assign bucket = "" | split: "" -%} {%- for event in include.events -%} {%- assign cutoff = event.end | default: event.start | date: "%Y-%m-%d" -%} {%- assign one = include.events | slice: forloop.index0, 1 -%} {%- if include.mode == "upcoming" -%} {%- if cutoff >= today -%} {%- assign bucket = bucket | concat: one -%} {%- endif -%} {%- else -%} {%- if cutoff < today -%} {%- assign bucket = bucket | concat: one -%} {%- endif -%} {%- endif -%} {%- endfor -%} {%- if include.mode == "upcoming" -%} {%- assign bucket = bucket | sort: "start" -%} {%- else -%} {%- assign bucket = bucket | sort: "start" | reverse -%} {%- endif -%}
